First regular KeePassDX-FIDO2 release: unlock KeePass databases on Android with a Token2 PIN+ Dual over NFC or USB-C, using a Token PIN or fingerprint.

- NFC is selected automatically when the device supports it and NFC is enabled.
- A saved biometric-protected token PIN starts Token + Fingerprint automatically.
- One token with a saved fingerprint PIN is selected directly, even when other tokens are enrolled. Multiple eligible tokens show “Token wählen”.
- Fingerprint cancellation leaves manual Token PIN entry available without repeated automatic prompts.
- Up to five alternative tokens, optional Key Files and Master Password recovery remain available.
- Standard KDBX compatibility, app package, signing identity and local enrollment/PIN formats are preserved.

Install the APK over the existing FIDO2 app; do not uninstall or clear app data. Android 13 or later; supported security key: Token2 PIN+ Dual with FIDO2 hmac-secret and a configured PIN.

The owner confirmed USB + fingerprint, NFC + fingerprint and automatic login defaults on their device. The final one-eligible-token picker refinement still needs device acceptance. Independent negative/recovery cases and broader device coverage are not exhaustive. This independent fork has not undergone an external security audit.

The APK is signed with the existing Ordanexa identity. SHA256SUMS and SOURCE_COMMIT identify the downloadable binary and its exact source. KeePassDX is GPL-3.0-or-later; the adapted Token2 NFC transport retains its MIT notice.
